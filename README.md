# Genlock: landing page (product concept)

Static landing page for **Genlock**, a SaaS concept that discovers every device on a broadcast network, works out what each device does from its code, APIs and documentation, instruments it automatically (metrics, logs and signal-path traces via OpenTelemetry), and feeds the analytics stack a broadcaster already runs. It also introduces the Genlock Certified device program (Level 1 Silver, Level 2 Gold, Level 3 Platinum) and the sample Genlock Partner Summit 2027.

Open `index.html` in a browser, or serve the folder with any static host (GitHub Pages, Netlify, an internal web server).

```
index.html                       the page (self-contained HTML/CSS, inline SVG badges)
assets/genlock-video.mp4         98 s intro video with captions and voiceover
assets/genlock-video-poster.jpg  video poster frame
```
