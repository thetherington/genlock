The problem

Monitoring stops where the known devices end.

Third-party blind spots

Devices without a ready-made collector go unmonitored, so faults show up on air before they show up on a dashboard.

Every new device is a project

Engineers hand-build collectors, map SNMP OIDs and write log parsers for each model and firmware release.

Data without meaning

Raw log lines and counters arrive with no device context, no severity and no link to the signal path.

On-prem overhead

Servers to buy, clusters to tune and upgrades to schedule, with each facility seen on its own.

How it works

From unknown device to fully observed, automatically.

  1. 01

    Discover

    Finds every device using NMOS, LLDP, SNMP and multicast flow sniffing.

  2. 02

    Identify

    Fingerprints vendor, model and firmware against a shared device graph.

  3. 03

    Understand

    AI reads code, MIBs, API specs and manuals to build a reviewed device profile.

  4. 04

    Instrument

    Generates metrics, log parsers and signal-path traces with OpenTelemetry.

  5. 05

    Certify

    Scores each device for observability and security, Levels 1 to 3.

Nothing installed on your devices

Closed devices are wrapped from outside by polling, listening and flow taps. Firmware is never modified.

Signal-path traces

Follow a stream hop by hop, camera to playout, to the device that degraded it.

Read-only by default

Passive-first discovery and rate-limited polling, safe for live production networks.

X-ray any device

See inside any device to learn what it can do.

X-rays revealed the gears of the Antikythera mechanism. Genlock does the same for every device: it looks inside, reads what is published about it online, and builds a profile of what the device is, how it works and everything it can tell you.

Closed firmware? Genlock relies on published MIBs, API specs, manuals and the device's observed behaviour, and vendors can contribute profiles through certification.

Integrations

Feeds the analytics stack you already run.

Genlock is not another place to store your data. Telemetry is enriched with device, site, signal path and certification level, then exported over OpenTelemetry or your vendor's ingest API, with prebuilt broadcast dashboards and alerts for each stack.

Device certification

Know which devices are observable before you buy.

Genlock Certified badges are versioned per firmware release and listed in a public registry you can reference in RFPs.

Level 1

Discoverable

Registers via NMOS IS-04 and publishes a documented SNMP MIB or REST API.

Level 2

Observable

Structured logs with a message catalog, health metrics and documented signal inputs and outputs.

Level 3

Instrumented and secure

Native OpenTelemetry export, AMWA BCP-003 security, signed firmware and a published SBOM.
